# 圆环与 6–11 通道细节更新

## 使用

直接打开项目根目录 `index.html`，不需要联网、构建工具或服务端。已有页面请刷新。

- 顶部“圆环 / 6–11 通道 / 卫生间”定位对应区域；在第一人称中点击可直接移动到该区域。
- 点击“第一视角”从当前地图焦点的最近可通行位置进入；再次点击返回当前位置的正交模型视角。
- WASD / 方向键移动，鼠标转向，Q/E转身，Shift加速；无法锁定鼠标时可拖动观察。
- 地图默认开启剖切，隐藏新增上墙和吊顶；第一人称显示完整高度。右上角仍可查看站台层与空间叠合。
- 小型 FPS / 绘制计数显示实际设备运行情况，不是预设性能数值。

## 空间约定

`StationDetails.layout` 使用与图纸一致的 `(u,v)` 布局值：`v` 从圆环向6–11出口增加；落到 Three.js 的世界坐标为 `(x,z)=(u,-v)`。这样正向行走时超市、进站口和11号支廊确实位于右手侧，6号支廊在左侧。只转换坐标朝向，出口相邻关系保持不变。此图没有测绘北向，界面使用“视向”。

| 锚点 | 图纸布局坐标 | 表达 |
|---|---|---|
| 圆环接口 | (0,7.5) | 与已有圆环连通 |
| 外展超市及岔路 | (11,13.2) | 自主廊向右深入约15，前段玻璃栏杆与设备凹位，深处超市入口、货架与收银台 |
| 安检进站区 | (7.4,21) | 位于超市之后，安检门正面朝向圆环来向，传送机、屏幕与闸机沿主廊方向排列 |
| 十字交汇 | (0,30) | 横廊宽约6.2，西侧仅6号口 |
| 独立7号支路 | (-5,36) | 与6号横廊之间有实体隔墙，无横向捷径 |
| 6号上行口 | (-15.5,31.5) | 位于十字廊西侧，楼梯扶梯顺圆环出站方向上行；与7号支路隔墙分开 |
| 11玻璃前厅 | (7.9,30) | 可穿过的透明隔断与11号总导向；左侧咖啡店 |
| 11A / 11B | (24.5,34.5) / (24.5,26) | 共用前厅后分别朝左、右两条走廊到独立楼梯，中央实体隔墙 |
| 卫生间入口 | (19,24.7) | 位于11B廊对面，由南侧入口进入；门外玻璃、灯环、暖金色点阵墙与标牌 |
| 洗手区 | (19,18.8) | 弧形格栅后方的镜面与三个示意盆位 |

模型单位约为米，视点在地面上1.65米附近。坐标、跨度、设备数量与家具尺寸属于视觉估算，不能用于施工或疏散计算。卫生间盆位是示意重复构件，不代表现场精确数量；未拍到的男女区后部以遮挡表示，未创建厕位或新连接。7–10号口的近景装饰不作推断。

## 代码与数据

- `assets/station-details.js`：区域布局、分层构件、标牌、碰撞体、剖切及纹理缓存。经典脚本公开 `StationDetails.layout/build` 给现有 viewer 使用，没有网络接口。
- `index.html`：继续管理原有车站模型、相机、拾取和输入；新增区域入口、视图切换、运行统计及静态构件实例化。
- `docs/素材与设施索引.md`：逐张原图索引及抽帧分组。原图与视频保持原路径，按原 `.gitignore` 排除在提交外。

通道可行走边界由实际构建地面的矩形配置组成；墙体、格栅、柜体、扶梯、售卖机等实体在构建时同步记录碰撞。仅实现B1步行，不模拟上扶梯到街面、刷卡进站或镜面反射。

## 验收记录

执行：`node scripts/check-station.cjs`。该脚本使用真实 Three.js 几何及变换、模拟 Canvas/DOM，检查场景构建与通行，不伪装 WebGL 测试。

已检查：

1. 圆环至出口的超市→进站口→十字口顺序；世界坐标下的右手侧正确。
2. 主廊、超市纵深岔路、安检前区、6号支廊、7号支路、11玻璃前厅与A/B独立支廊连续通行。
3. 卫生间从11B廊对面进入，绕过格栅到洗手区可通行；台柜和外墙不能穿越。
4. 6与7横廊之间不能穿过；11A/B在分叉后由实体隔墙分开。
5. 男左女右、标牌无负向纹理重复，图纸坐标转换后文字变换保持正向。
6. 地图剖切与第一人称完整高度、地图焦点原位进入、相机横移与鼠标方向。
7. 场景无非有限变换；标牌尺寸有效；文字纹理缓存复用。

静态统计与最终执行结果以脚本输出为准。基线构件及新增构件按材质实例化，细化后首次统计约575个地图绘制组、11.6万三角形（含实例展开）；这些是CPU场景统计，不等于GPU实测绘制次数或帧率。实际值显示在页面左上区域栏中。

**待完成的实机验收：** 当前浏览器对本地文件页面的访问受限，未取得本轮页面截图、浏览器控制台记录和1080p实测FPS；不把静态检查视为视觉或性能验收通过。目标仍为普通行走持续30 FPS。请在允许访问本地页的浏览器中依次查看“圆环、6–11通道、卫生间”，观察文字正面、明暗、材质穿插及运行计数。

## 估算与简化

店面角度依据照片重叠顺序和既有出口锚点安排，门面宽度为适配现有圆环的估算；不假定25张照片对应25个等分角。广告保留大字与主色构图，不复制人物肖像与小字。镜面为金属色简化表面，广告为静态缓存纹理，没有实时视频、动态反射或大量附加灯光。
